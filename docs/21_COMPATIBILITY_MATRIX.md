## Validation Areas

- HOME role
- lifecycle
- package discovery
- permission behavior
- notification access
- default app roles
- background limitations
- device-management provisioning
- performance
- screen dimensions/aspect ratios
- navigation buttons vs gesture navigation

## Compatibility Rule

A device is not "supported" simply because the app installs.

It is supported only when the core experience passes the compatibility acceptance checklist.
