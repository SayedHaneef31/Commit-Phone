# Smartphone-to-Keypad Phone

An Android product that transforms a modern smartphone into a real keypad-phone experience while retaining only the modern tools the user genuinely needs.

## Core Idea

> The phone is a tool. The user is in control.

This is not a generic minimalist launcher.

It is a commitment-based smartphone-to-dumbphone transformation experience.
